# Pinned exactly. control.ai.supply.model_pinned is about more than the model: a floating dependency
# changes behaviour under you between two deploys of the same commit, and the resulting bug is
# untraceable because nothing in your repository changed.
#
# Verified to install on CPython 3.11 through 3.14. An earlier version of this file pinned pydantic
# 2.10, which has no wheel for 3.14 — pip fell back to building pydantic-core from source, needed a
# Rust toolchain, and failed. A pin that does not install is not a pin, it is a trap.

# missing package at the first model call rather than at startup.
