# Interface design

- [ ] Read the brief and `standards/17-design-quality.md` before any interface code.
- [ ] Ask only what is missing: users, main task, references the owner likes, looks they veto.
- [ ] Propose two or three directions with palette, typefaces and licences, density, the bold element and costs.
- [ ] Label a recommendation; the owner chose the direction and, separately, the icon family.
- [ ] Write `design/brief.md` and `design/tokens.json` (DTCG 2025.10) with font licences and contrast pairs.
- [ ] Generate platform variables from the tokens; interface code uses tokens only.
- [ ] Critique screenshots at 375, 768 and 1280 px against the brief and the tells; remove one accessory.
