# Software design

- [ ] Inspect the existing architecture and constraints before choosing components.
- [ ] Record consequential decisions and alternatives in an ADR.
- [ ] Define interfaces, data ownership, authorization, and compatibility at actual boundaries.
- [ ] For UI, cover journeys, error states, keyboard access, labels, and responsiveness.
- [ ] Identify introduced risks, verification, and recovery without speculative layers.
