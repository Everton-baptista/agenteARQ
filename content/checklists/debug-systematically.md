# Systematic debugging

- [ ] Capture expected behavior, observed failure, revision, and reproducer.
- [ ] Form a falsifiable hypothesis and run a discriminating check.
- [ ] Distinguish environment failures from product defects.
- [ ] Add a regression test, fix the cause, and verify original and nearby behavior.
- [ ] Record cause, evidence, and limits; never solve a failure by widening privileges.
