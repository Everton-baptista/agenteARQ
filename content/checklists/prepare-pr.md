# Prepare a pull request

- [ ] Final revision satisfies required acceptance checks and independent review.
- [ ] Inspect the final diff and resolve blocking findings.
- [ ] Describe problem, resulting behavior, verification, and material limitations.
- [ ] Publish only through an authorized mechanism; report missing prerequisites honestly.
- [ ] Stop at the requested PR deliverable without inferring permission to merge or deploy.
