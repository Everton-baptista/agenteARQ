# Persona runs

- [ ] Run the product locally or in the sandbox; drive it from a host subagent through a browser-automation MCP server.
- [ ] Record the model id, step cap, budget and runs per persona; keep traces without content.
- [ ] Use only the real interface each persona would have.
- [ ] Report each finding with reproduction steps and "seen in k of n runs"; never report a pass.
- [ ] Replay findings with a plain browser test; promote only reproduced ones, with owner approval.
